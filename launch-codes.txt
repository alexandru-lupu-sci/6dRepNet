To launch the head tracker, run this command in the terminal from the project folder:

.venv\Scripts\python.exe 6D-Cuda-v1.2_LAB.py

(Or using uv: uv run 6D-Cuda-v1.2_LAB.py)

Notes:
- This project uses a single virtual environment (.venv), managed by uv (pyproject.toml / uv.lock),
  configured with CUDA-enabled PyTorch for NVIDIA GPUs (with automatic CPU fallback if no NVIDIA GPU is detected).
- Earlier reference script (not used for lab launches):
  .venv\Scripts\python.exe 6D-Cuda-v1.1.py
